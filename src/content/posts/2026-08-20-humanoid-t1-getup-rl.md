> **导读**：在复杂物理交互与高动态对抗环境（如高机动足球、工业巡检、非平整地形移动）中，人形机器人的“跌倒”不是偶发异常，而是不可避免的常态。如何让一台 20+ 自由度的全尺寸/中型人形机器人，在遭遇仰卧、俯卧、侧摔甚至扭曲倒地的任意极值姿态下，不依赖人工扶起、自主且鲁棒地重新站立？
>
> 传统的基于预设关键帧轨迹插值的方法在面对连续接触碰撞与多姿态扰动时极易失效。本文系统性解构基于新一代 GPU 并行物理仿真引擎（MuJoCo GPU / mjlab）的人形机器人全向自主起身强化学习方案：从接触求解器稳定性优化、非受控沉降窗口机制（Settle Window）、“上帝之手”虚拟外力课程（HoST-style Force Curriculum）与锚点环境（Anchor Environments），到乘法防作弊任务奖励函数（Task-Product Reward）与分层恢复监控状态机（Recovery Supervisor），提供一套高鲁棒性的算法与工程闭环。
>
> **阶段说明**：当前整套方法已在多物理引擎与高动态对抗仿真（Sim / Sim2Sim）中完成严格的批量全向闭环验证；我们将其作为坚实的控制与安全底座，后续将进一步推进真实硬件实机（Sim2Real）的落地部署与抗冲击迁移。

## 1. 人形机器人全向起身的动力学本质与探索困境

### 1.1 为什么全向自主起居是具身智能的“生存基石”

在经典的四足机器人领域，由于质心低、支撑面大且各向同性对称，翻滚与起身通常可以通过简单的启发式或预规划动作完成。然而对于高质心、窄支撑基底、具有 20 自由度以上的人形机器人而言，跌倒恢复（Fall Recovery / Get-Up）在运动学与动力学上面临着截然不同的维度鸿沟：

```
                    ┌─────────────────────────┐
                    │    高动态交互 / 跌倒    │
                    └────────────┬────────────┘
                                 ▼
                    ┌─────────────────────────┐
                    │ 任意 3D 随机位姿碰撞落体 │
                    │ (仰卧 / 俯卧 / 侧翻扭曲) │
                    └────────────┬────────────┘
                                 ▼
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
┌─────────────────────────────┐         ┌─────────────────────────────┐
│    传统方法 (Keyframe)      │         │     强化学习 (RL Policy)    │
├─────────────────────────────┤         ├─────────────────────────────┤
│ ❌ 依赖固定初态，碰撞即卡死  │         │ ✅ 全向连续感知与动态自适应 │
│ ❌ 缺乏柔顺性，易烧毁电机    │         │ ✅ 泛化适应各种复杂接触拓扑 │
│ ❌ 需手工调校数十种过渡姿态  │         │ ✅ 端到端闭环恢复至平衡站姿 │
└─────────────────────────────┘         └─────────────────────────────┘
```

传统方法通常依赖**固定关键帧插值（Keyframe Replay）**。其致命缺陷在于：现实中的摔倒姿态是连续无限的，地面微小的摩擦差异或肢体微小的卡顿，都会使开环插值轨迹脱离预设吸引子，导致肢体持续对抗硬限位甚至烧毁执行器。因此，**基于闭环反馈感知的深度强化学习（Deep Reinforcement Learning, DRL）成为解决多姿态全向起身的唯一通途。**

---

### 1.2 强化学习直接求解起身的致命痛点

若直接采用标准 PPO（Proximal Policy Optimization）算法在随机倒地姿态下进行端到端训练，算法在绝大多数情况下会迅速收敛到次优死锁甚至完全无法收敛。其内在物理机理包含以下三大困境：

1. **极端非连续接触动力学（Discontinuous Contact Dynamics）**：
   从平躺到直立的过程中，机器人的躯干、大腿、小腿、脚掌以及双臂会发生高频且不可导的接触建立与断开。接触瞬间的冲量传递会导致状态转移概率发生剧烈跃变，严重破坏策略梯度的平滑性。
2. **探索空间的严重稀疏性与重力势能陷阱（Potential Energy Trap）**：
   机器人要想站起，必须先将四肢收拢、翻身、建立支点、再克服重力势能将质心举升。在初始随机探索阶段，机器人偶尔挥动手臂或乱蹬双腿所获得的局部势能变化几乎为零，算法无法感知有效的向上梯度。
3. **高维关节自锁与“四肢抽搐”局部最优（Local Optima & Kinematic Deadlock）**：
   在没有引导的情况下，机器人极易学会“趴在地上拼命挥动手臂”或者“双腿极度深蹲抱团”，因为这些动作在早期能够避免倾倒惩罚，从而陷入局部的鞍点无法自拔。

## 2. GPU 物理仿真底座与动力学建模工程

### 2.1 基于 GPU 显存级并行的环境吞吐范式

面对上述挑战，我们基于 GPU 加速的物理仿真平台（如基于 NVIDIA Warp / MuJoCo 架构的 `mjlab` 环境体系），构建大规模并行采样管线。

与传统 CPU 仿真中环境间通信开销巨大不同，GPU 原生并行框架将成千上万个机器人环境的刚体状态、关节位置、接触雅可比矩阵以及执行器输出全部常驻于 GPU 显存中：

```
┌─────────────────────────────────────────────────────────────────┐
│                      GPU Global Memory (VRAM)                   │
├────────────────────────────────┬────────────────────────────────┤
│  mjlab Parallel Envs (N=4096)  │  RSL-RL On-Policy PPO Runner   │
│  - Tensorized State q, v       │  - Actor-Critic MLP            │
│  - Warp-based Physics Step     │  - Rollout Storage Buffer      │
│  - Direct Wrench & Sensor API  │  - Zero-Copy Tensor Pipeline   │
└────────────────────────────────┴────────────────────────────────┘
```

整个强化学习采样、奖励计算、策略前向推理与 PPO 梯度反向传播实现了**显存内零拷贝闭环（Zero-Copy Rollout）**，使得策略能够在数小时内积累相当于数周的物理交互时长。

### 2.2 接触求解器选型：CG 与 Newton 的高冲击稳定性之争

在构建强化学习环境时，很多工程师往往默认采用牛顿迭代类求解器（Newton Solver）。然而在人形机器人跌倒恢复任务中，这是一个常见的“隐形杀手”。

> #### 💡 工程师实战避坑笔记：接触奇异性与求解器崩溃
> 在多姿态摔倒初始化阶段，机器人肢体以随机角速度撞击地面，接触瞬间的法向冲击与关节速度可瞬间激增（$\dot{q} > 40\text{ rad/s}$）。
> - **Newton 求解器**：其 Hessian 矩阵在强碰撞奇异点（特别是双脚或手肘瞬时卡入地表接触网格）极易出现非正定或条件数恶化，导致迭代发散并抛出 `NaN/Inf`，造成仿真崩溃。
> - **共轭梯度求解器（Conjugate Gradient, CG Solver）**：采用基于能量极小化的一阶/共轭梯度迭代，对高接触速度和强摩擦锥约束表现出极佳的数值鲁棒性，即便在极端姿态挤压下仍能保持能量收敛。

在仿真配置中，我们统一将求解器配置为共轭梯度（CG），并配合椭圆摩擦锥（Elliptic Cone）约束：

$$
\min_{\mathbf{v}} \frac{1}{2} (\mathbf{v} - \mathbf{v}_{\text{free}})^T \mathbf{M} (\mathbf{v} - \mathbf{v}_{\text{free}}) + \Psi_{\text{contact}}(\mathbf{v})
$$

### 2.3 关键机制：非受控沉降窗口（Settle Window）

在强化学习训练中，每个 Episode 开始时通常会将机器人重置（Reset）到空中一定高度，赋予随机三维姿态四元数 $\mathbf{q}_{\text{quat}} \in \mathbb{H}$ 与随机线速度/角速度，使其自然跌落。

```
 [Episode Reset: 空中抛落]
           │
           ▼
 ┌──────────────────────────────────────────────┐
 │   非受控沉降窗口: t ∈ [0, τ_settle]          │
 │   • 抑制网络策略输出 (Action Suppressed)     │
 │   • 电机保持当前关节位置 (Hold Position)     │
 │   • 自由落体与地表碰撞能量耗散               │
 └─────────────────┬────────────────────────────┘
                   │
                   ▼ 机器人完全落地静止
 ┌──────────────────────────────────────────────┐
 │   策略接管激活: t > τ_settle                 │
 │   • DRL 闭环控制启动 (Action Enabled)        │
 │   • 从真实物理静止/准静止接触状态开始起身    │
 └──────────────────────────────────────────────┘
```

#### 为什么必须设计 Settle 机制？
如果机器人刚在空中初始化，策略网络立刻接管并输出动作：
1. 网络在空中做出的动作会与空气产生无力臂的空挥，一旦触地瞬间，处于非平衡受力状态的四肢会受到巨大的非物理冲量反噬；
2. 导致策略学习到“空中预先摆姿态利用重力反弹”等无法迁移至实机的脆弱 Trick。

**设计方案**：构建带沉降保护的相对关节动作执行器（`SettleRelativeJointPositionAction`）。在重置后的前 $\tau_{\text{settle}}$ 个环境步内，强制屏蔽神经网络的动作增量，仅让执行器维持当前被动阻尼位置。待机身与地面完成初始接触并消耗掉自由落体动能后，策略才正式接管。

## 3. 核心引导范式：HoST 虚拟外力课程与锚点环境

即便解决了仿真物理底座的稳定性，单纯依靠策略在平地上自由摸索，其探索成功率依然极低。为此，我们引入并改进了基于虚拟外力辅助的人形机器人站立控制课程（HoST-style Force Curriculum）。

```
        初始阶段: 高外力辅助                     中后期: 渐进自适应脱模                     最终阶段: 完全自主
 ┌───────────────────────────────┐     ┌───────────────────────────────┐     ┌───────────────────────────────┐
 │ 向上辅助力 F_z ≈ 60% 自重     │ ──► │ 随单机站立成功次数逐步衰减    │ ──► │ 辅助力归零 (F_z = 0 N)        │
 │ 策略快速发现"收腿-撑地"拓扑   │     │ F_z ← max(0, F_z - ΔF)        │     │ 纯自主全向动力学起身          │
 └───────────────────────────────┘     └───────────────────────────────┘     └───────────────────────────────┘
```

---

### 3.1 虚拟外力辅助（Helping Hand）的物理引导思想

我们在机器人的躯干（Trunk）几何中心施加一个沿全局世界坐标系 $Z$ 轴正方向的虚拟外力 $\mathbf{F}_{\text{ext}}$：

$$
\mathbf{F}_{\text{ext}} = \begin{bmatrix} 0 \\ 0 \\ F_z \end{bmatrix}, \quad F_z \in [0, F_{\text{init}}]
$$

在训练初期，设置 $F_{\text{init}}$ 约为机器人自身重力的 $50\% \sim 70\%$。
- **物理效果**：该外力相当于一只“上帝之手”轻轻向上提拉机器人的躯干，极大地抵消了翻身和起立时对抗重力势能的阻力矩。
- **探索收益**：策略网络能够在极短的迭代步数内发现正确的动作拓扑——“先收拢双腿、将脚底与手臂置于躯干下方构建支撑三角、然后蹬地伸髋”。

---

### 3.2 随成功率自适应衰减与辅助力状态感知闭环

如果外力是静态恒定的，策略网络将对辅助力产生永久依赖。因此必须建立**去中心化的环境级自适应衰减逻辑**：

```
                ┌──────────────────────────────────────┐
                │          单个环境 Episode 结束       │
                └──────────────────┬───────────────────┘
                                   │
                         是否达到稳定站立标准？
                         (高度 > h_thresh 且 直立度 > θ_thresh)
                                   │
                   ┌───────────────┴───────────────┐
                   │ 是                            │ 否
                   ▼                               ▼
     ┌───────────────────────────┐   ┌───────────────────────────┐
     │ 当前环境辅助力步进衰减:    │   │ 保持当前环境辅助力水平    │
     │ F_z ← max(F_min, F_z - ΔF)│   │ 继续学习当前难度          │
     └───────────────────────────┘   └───────────────────────────┘
```

#### 关键技术点：辅助力状态感知（Assistance Ratio Observation）
为了让同一个神经网络策略在面对不同辅助力水平时能够自适应调整自身力矩输出，我们将**归一化辅助力比例**显式作为观测项输入给策略网络：

$$
\alpha_{\text{assist}} = \frac{F_z}{F_{\text{init}}} \in [0.0, 1.0]
$$

- 当 $\alpha_{\text{assist}} \to 1.0$ 时，网络学会协同外力进行姿态校正；
- 当 $\alpha_{\text{assist}} \to 0.0$ 时，网络平滑过渡到利用自身执行器输出满额扭矩蹬地起立。

---

### 3.3 锚点环境（Anchor Environments）：破解灾难性遗忘

在多环境并行课程学习中，随着训练推进，绝大多数环境的辅助力都会衰减到 $0\text{ N}$。此时会出现一个严重的工程痛点：**灾难性遗忘（Catastrophic Forgetting）**。

> #### 💡 工程师实战避坑笔记：高阶课程对基础能力的侵蚀
> 当所有环境的 $F_z$ 降至 $0$ 后，机器人一旦遇到极难的翻滚姿态导致起立失败，网络中关于“如何在极端扭曲姿态下借力翻身”的早期探索梯度早已被冲刷殆尽，导致策略在后期陷入局部振荡。
>
> **破局设计：锚点环境（Anchor Environments）**
> 我们在全部并发环境中，固定划分出一定比例 $\eta_{\text{anchor}} \in (20\%, 30\%)$ 的环境作为“锚点”：
> - 锚点环境的辅助力永远锁定在 $F_{\text{init}}$，不随成功次数递减；
> - 无论全局训练进行到何种阶段，锚点环境持续不断地为策略网络提供多姿态、大范围翻滚的充沛探索样本与梯度流，彻底消除了策略对极端摔倒姿态的遗忘效应。

## 4. MDP 建模与反“作弊”奖励工程

### 4.1 观测空间与动作空间结构化设计

我们将起居任务建模为部分可观测马尔可夫决策过程（POMDP）。

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Actor Observation (75D)                         │
├───────────────────┬────────────────────────────────────────────────────┤
│ 躯干角速度 (3D)   │ IMU 陀螺仪滤波数据: \omega_b                       │
│ 投影重力向量 (3D) │ 重力在机身坐标系的投影: \mathbf{g}_b = \mathbf{R}^T \mathbf{g}_w │
│ 相对关节位置 (23D)│ 当前关节编码器与标称姿态之差: q - q_{nominal}      │
│ 相对关节速度 (23D)│ 关节瞬时角速度: \dot{q}                            │
│ 历史动作反馈 (23D)│ 上一时刻策略网络输出: a_{t-1}                      │
│ 辅助力感知 (1D)   │ 归一化外力比例: \alpha_{assist}                    │
└───────────────────┴────────────────────────────────────────────────────┘
```

* **动作空间表征**：
  策略网络输出相对关节位置增量 $\Delta \mathbf{a} \in [-1, 1]^{N_{\text{joint}}}$，结合动作缩放系数 $\alpha_{\text{scale}}$ 与关节软限位进行映射：

  $$
  \mathbf{q}_{\text{target}} = \text{clip}\left(\mathbf{q}_{\text{current}} + \alpha_{\text{scale}} \cdot \Delta \mathbf{a}, \; \mathbf{q}_{\text{min}}, \; \mathbf{q}_{\text{max}}\right)
  $$

  再通过关节底层的 PD 控制器跟踪目标位置：

  $$
  \boldsymbol{\tau} = \mathbf{K}_p (\mathbf{q}_{\text{target}} - \mathbf{q}) - \mathbf{K}_d \dot{\mathbf{q}}
  $$

### 4.2 核心创新：乘法任务奖励（Task-Product Multiplicative Reward）

在强化学习任务设计中，传统的任务奖励多采用加权求和（Additive Reward）：

$$
r_{\text{naive}} = w_1 r_{\text{height}} + w_2 r_{\text{orient}}
$$

#### 传统加权求和的“奖励黑客（Reward Hacking）”缺陷：
策略网络极具“投机性”。在线性加和形式下，机器人往往会学会两种极端的作弊动作：
1. **躺平刷高度**：身体完全平躺在地上，把双腿高高举向空中，以此骗取可观的 $r_{\text{height}}$ 收益；
2. **地表陀螺翻滚**：四肢完全不站立，仅在地面快速翻转机身朝向，以此刷取 $r_{\text{orient}}$ 收益。

#### 乘法任务奖励（Task-Product Multiplicative Reward）：
为了从数学上彻底根治策略作弊，我们采用**乘法任务奖励结构**：

$$
r_{\text{task}} = r_{\text{orient}} \times r_{\text{height}}
$$

```
       直立奖励 r_orient                         高度奖励 r_height (Sigmoid)
   1.0 ┌───────────────┐                    1.0 ┌───────────────────────┐
       │               │                        │                  .─── │
       │       .────── │                        │               .─'     │
       │    .─'        │                        │           .─'         │
   0.0 └───┴───────────┘                    0.0 └───┴───────┴───────────┘
     倒地 (-1)      直立 (+1)                      地面     过渡区   目标高度
```

具体的物理形式定义如下：

1. **机身直立朝向奖励 $r_{\text{orient}}$**：
   衡量机身局部坐标系的重力反向对齐程度（机身 $Z$ 轴向上）：
   $$
   r_{\text{orient}} = \max\left(0, \; -g_{z}^b\right)
   $$
   当机器人平躺在地面时 $r_{\text{orient}} = 0$；当完全直立时 $r_{\text{orient}} = 1.0$。

2. **质心高度奖励 $r_{\text{height}}$**：
   采用平滑的 Sigmoid 激活函数，在质心接近目标站姿高度 $h_{\text{target}}$ 时提供梯度激励：
   $$
   r_{\text{height}} = \frac{1}{1 + \exp\left(-\frac{h - h_{\text{target}} + \frac{m}{2}}{m / 6}\right)}
   $$
   其中 $m$ 为过渡平滑边际裕度。

$$
\text{核心原理：} \quad r_{\text{task}} = \underbrace{r_{\text{orient}}}_{0 \text{ (平躺)}} \times \underbrace{r_{\text{height}}}_{1 \text{ (举腿)}} = 0 \quad \Longrightarrow \quad \text{彻底粉碎局部作弊解！}
$$

只有当机器人**机身既直立、质心又升至站立高度时**，$r_{\text{task}}$ 才能同时获得正值，迫使策略必须完成完整的起立动作链路。

### 4.3 物理一致性与防死锁多约束系统

除了主任务奖励外，为了确保起身后姿态优美、关节不产生物理死锁与机构损坏，必须构建多维辅助正则项体系：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        多维物理一致性辅助约束体系                      │
├───────────────────────────┬────────────────────────────────────────────┤
│ 1. 膝关节过度屈曲惩罚     │ 惩罚膝关节超过极限屈曲角，防止深蹲机构自锁 │
│ 2. 双足跨距惩罚           │ 惩罚双脚距离超出合理站姿宽度，严防大劈叉   │
│ 3. 手臂速度阻尼惩罚       │ 抑制开臂架构下的手臂盲目高速挥舞           │
│ 4. 站稳静态平衡奖励       │ 站立后给予机身低线速度/角速度正向激励      │
│ 5. 机械功率终止课程       │ 随训练阶段逐步限制最大瞬时功率，过滤假性起振│
└───────────────────────────┴────────────────────────────────────────────┘
```

1. **膝关节过度屈曲惩罚（Knee Over-Flexion Penalty）**：
   人形机器人的膝关节传动连杆在深蹲极限角附近力矩输出受限。若机器人双膝极度弯曲压在身下，将丧失有效力臂。惩罚项为：
   $$
   p_{\text{knee}} = -\sum_{i \in \text{knees}} \max\left(0, \; q_{i} - q_{\text{knee\_max}}\right)
   $$

2. **双足跨距惩罚（Feet Distance Constraint）**：
   防止机器人在起身后通过大跨度“劈叉”来维持虚假平衡：
   $$
   p_{\text{feet}} = -\max\left(0, \; \|\mathbf{p}_{\text{left\_foot}}^{xy} - \mathbf{p}_{\text{right\_foot}}^{xy}\| - d_{\text{max}}\right)
   $$

3. **手臂速度阻尼惩罚（Arm Velocity Damping）**：
   在很多开臂人形机器人构型中，手臂自然下垂状态具有一定的展开角。如果盲目惩罚手臂偏离特定目标位置，会与动态支撑动作发生冲突。因此，我们选择**仅惩罚手臂关节的高速挥舞（$L_2$ 范数）**：
   $$
   p_{\text{arm}} = -\sum_{j \in \text{arms}} \dot{q}_j^2
   $$

4. **站立后静态平衡奖励（Stand-Still Reward）**：
   一旦机器人达到直立高度，激励其躯干保持线速度与角速度接近于零，避免原地踏步或高频晃动：
   $$
   r_{\text{still}} = \exp\left(-c_1 \|\mathbf{v}_{\text{trunk}}^{xy}\|^2\right) + \exp\left(-c_2 \|\boldsymbol{\omega}_{\text{trunk}}\|^2\right)
   $$

5. **机械功率/能量终止课程（Mechanical Energy Curriculum）**：
   计算全机关节瞬时机械功率 $P_{\text{mech}} = \sum |\tau_i \cdot \dot{q}_i|$。在训练初期放宽功率上限允许剧烈翻滚；随着训练轮次推进，逐步收紧功率阈值，并在功率超限时强制触发 Episode 终止（Termination），促使网络演化出节能、柔顺的起移动力学。

## 5. 域随机化与鲁棒性增强

为了确保在 mjlab 训练得到的起居策略具备强大的泛化性，我们设计了全方位的动力学与感知域随机化（Domain Randomization, DR）管线。

```
                       ┌─────────────────────────┐
                       │     域随机化管线 (DR)   │
                       └────────────┬────────────┘
                                    │
          ┌─────────────────────────┼─────────────────────────┐
          ▼                         ▼                         ▼
┌──────────────────┐      ┌──────────────────┐      ┌──────────────────┐
│   接触摩擦随机化 │      │   本体动力学扰动 │      │   感知与偏置扰动 │
├──────────────────┤      ├──────────────────┤      ├──────────────────┤
│ • 滑动摩擦 (0.3~1.5)│   │ • 躯干质心 3D 偏移 │   │ • 编码器初始偏置 │
│ • 自旋摩擦 (对数)│      │ • 连杆质量/惯量扰动│   │ • 陀螺仪高斯白噪 │
│ • 滚动摩擦 (对数)│      │ • 关节限位软边界   │   │ • 50Hz 离散观测延迟│
└──────────────────┘      └──────────────────┘      └──────────────────┘
```

### 5.1 接触摩擦的多轴对数随机化
地表与足底/机身碰撞体之间的交互不仅包含切向滑动，还包含法向自旋与滚动阻尼：
- 滑动摩擦系数（Sliding Friction）：$f_{\text{slide}} \sim \mathcal{U}(f_{\text{min}}, f_{\text{max}})$；
- 自旋摩擦系数（Spinning Friction）与滚动摩擦系数（Rolling Friction）：采用**对数均匀分布（Log-Uniform Distribution）**跨越数个数量级进行采样，使策略对光滑瓷砖、草坪、人工草皮等不同材质均具备极高自适应能力。

### 5.2 本体动力学与感知通道扰动
- **躯干质心 3D 偏移（CoM Offset）**：在机身中心施加 $\Delta \mathbf{p}_{\text{CoM}} \sim \mathcal{U}(-\boldsymbol{\delta}, \boldsymbol{\delta})$ 扰动，模拟电池安装公差与机载外设重量分布差异；
- **关节编码器偏置（Encoder Bias）**：在每次初始化时注入固定的零点偏移误差，防止策略过度依赖高精度绝对角度测量；
- **重置全向姿态池（Uniform Quaternion Sampling）**：在单位四元数流形 $\mathbb{S}^3$ 上均匀采样初始朝向，确保覆盖 $360^\circ$ 全向翻滚起始态。

## 6. 工业级系统集成：分层恢复状态机（Recovery Supervisor）

将一个孤立训练出的强化学习起居 Policy 嵌入到整机控制或高对抗比赛系统（如 RoboCup 3D / 实机足球 7v7）中，绝非简单调用 `run_network()`，而是必须建立一套严密的分层恢复监控状态机（Recovery Supervisor）。

```text
stateDiagram-v2
    [*] --> SOCCER : 比赛正常进行
    
    SOCCER --> FALLEN_DEBOUNCE : 触发跌倒检测 (is_fallen)
    
    FALLEN_DEBOUNCE --> SOCCER : 偶发碰撞回正 (Debounce 滤波)
    FALLEN_DEBOUNCE --> GETUP_RL : 连续 N 帧确认倒地
    
    state GETUP_RL {
        [*] --> RL_INFERENCE : 50Hz 闭环策略接管
        RL_INFERENCE --> STABILIZE : 达到站立判定 (is_standing)
        RL_INFERENCE --> TIMEOUT_ABORT : 超过最大步数 MAX_STEPS
    }
    
    STABILIZE --> POST_RECOVERY_ALIGN : 连续保持稳定 M 帧
    STABILIZE --> GETUP_RL : 再次失去平衡
    
    POST_RECOVERY_ALIGN --> SOCCER : 航向校正完毕 / 交还步态控制
    TIMEOUT_ABORT --> SOCCER : 触发安全兜底回退
```

---

### 6.1 从单点 Policy 到比赛级系统的闭环流转

如上述状态机所示，整个控制闭环包含以下关键防护层：

1. **跌倒防抖确认（FALLEN_DEBOUNCE）**：
   在剧烈拼抢或急停变向时，机器人躯干可能产生瞬时大倾角。为避免误触发起身策略，系统设置防抖计数器，只有当重力投影向量连续维持在倾倒区间超过 $N_{\text{debounce}}$ 帧时，才正式剥夺上层步态控制权。
2. **50Hz 严格推理周期保持（Zero-Order Hold）**：
   底层物理引擎或硬件通讯可能以更高频率（如 200Hz~1000Hz）运行。起身策略严格锁定在 50Hz 周期进行网络推理，并在子物理步之间对目标位置实施零阶保持（Zero-Order Hold），杜绝由于通讯抖动导致的策略失步。
3. **站稳门禁判定（Stable Hold Gate）**：
   绝对不能在策略单帧检测到直立的一瞬间就交还控制权。系统要求质心高度 $h > h_{\text{stand}}$ 且投影重力 $-g_z^b > \theta_{\text{upright}}$ **连续稳定保持 $M_{\text{hold}}$ 个控制周期**，才确认起身成功。
4. **起身后航向动态校正（Post-Recovery Align）**：
   机器人起身后的朝向通常偏离跌倒前的运动目标。在恢复稳定后，系统启动动态偏航角调整算法，平滑旋转至目标航向，再安全无缝交还给行走步态网络（Walk Policy）。

### 7.2 迈向真实世界：Sim2Real 迁移的挑战与攻坚方向

需要指出的是，**当前系统仍处于高保真仿真（Simulation）阶段**。虽然我们在仿真中引入了深度的物理一致性约束与多维域随机化，但要将该策略零样本或微调迁移到真实的人形机器人本体上，仍面临“Sim2Real Reality Gap”的工程硬仗。后续的攻坚重点将聚焦于以下四大维度：

1. **真实执行器非线性动力学建模（Actuator Dynamics & Bandwidth）**：
   - 真实机器人的行星减速机/谐波减速器存在反向间隙（Backlash）、摩擦死区及力矩响应带宽限制；
   - **后续规划**：采集实机硬件在阶跃与正弦激励下的真实力矩-速度响应数据，训练神经网络执行器模型（Actuator Net）并将其嵌入仿真训练环境，消除电机响应延迟鸿沟。
2. **实机接触柔顺性与硬件过载保护（Peak Torque & Thermal Safety）**：
   - 起身过程中肢体对硬质地面的猛烈冲击可能触发实机驱动器的过流/过温保护或损伤机械结构；
   - **后续规划**：在真机端引入基于末端力/电流反馈的主动柔顺阻抗控制，并在 Sim 训练中进一步收紧峰值力矩与冲击功耗惩罚。
3. **真实传感器非理想特性滤波（Sensor Noise & Latency）**：
   - 真实 IMU 在受到地面剧烈碰撞冲击时容易产生高频振动噪声与积分漂移；
   - **后续规划**：引入基于扩展卡尔曼滤波（EKF）的状态估计融合，结合时间延迟随机化（Latency Randomization），提升观测通道的抗冲击滤波能力。
4. **渐进式实机试验与安全绳（Gantry）辅助脱模**：
   - 借鉴 HoST 思想，在实机初步调试时通过桁架悬吊安全绳（Gantry Crane）提供渐进衰减的物理保护与辅助拉力，实现平稳、安全的实机 Sim2Real 过渡。
